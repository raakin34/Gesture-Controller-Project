# 🤖 Hand Gesture Controlled RC Car

This project implements a hand-based gesture controller for a remote-control car using neural networks and calibration techniques to achieve low latency and high accuracy. It enables users to control the car’s movements through intuitive hand gestures, replacing traditional input methods and creating a more engaging and accessible experience.

The repository covers:

✅ Gathering requirements for gesture-based control

✅ Designing and training a gesture recognition model

✅ Integrating the model with the RC car’s control system

✅ Evaluating performance, accuracy, and real-time responsiveness

This solution demonstrates how gesture recognition can be applied to real-world control systems, offering an interactive and futuristic way to operate devices.

## 🛠 Tools Used

Python – Programming language for data processing, model training, and integration

OpenCV – Computer vision library for hand detection and tracking

TensorFlow / Keras – Neural network framework for gesture recognition model

Edge Impulse – Platform for building and deploying ML models on embedded devices

NumPy & Pandas – Data handling and preprocessing

Arduino / Raspberry Pi – Hardware platform for controlling the RC car

Serial Communication – Interface between the gesture controller and the car

Fusion 360 (Fusion CAD) – 3D design and modeling for custom RC car parts

Matplotlib / Seaborn – Visualization of gesture data for analysis and debugging

## 📂 Project Files

File Description

Directions.ino	-  Arduino code that controls the RC car’s movements based on the gestures detected.

FinalAngles.ino - 	Arduino code that determines the corresponding gestures and maps them to specific angles/movements.

Gestures_inferencing.zip - 	Machine learning files and models used for gesture recognition and interfacing with the RC car.

Project Report.pdf - 	Professional report documenting the project, methodology, results, and analysis.

README.md - Project overview, setup instructions, and documentation.
